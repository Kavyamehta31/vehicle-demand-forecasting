# Vehicle Demand Forecasting System

## Project Overview

This project forecasts vehicle spare-part demand using historical demand data and compares multiple forecasting models through an interactive dashboard.

## Business Problem

Accurate demand forecasting helps optimize inventory, reduce stock-outs, and improve supply chain planning.

## Dataset

- 2070 forecasting series
- 24 months historical data
- Vehicle-wise demand records

## Methodology

1. Data Preprocessing
2. Monthly Demand Aggregation
3. Feature Engineering
4. Forecasting
5. Evaluation
6. Dashboard Visualization

## Models Implemented

- Moving Average
- Simple Exponential Smoothing (SES)
- Holt Trend Model
- ARIMA
- Recursive Linear Regression

## Evaluation Metrics

- MAE
- MAPE
- Accuracy

## Dashboard Features

- Executive Summary
- Model Comparison
- Forecast Explorer
- Download Reports
- Model Wise Comparison
- Forecast Analytics

## Results

| Model                       | Accuracy |
| --------------------------- | -------: |
| Moving Average              |   70.54% |
| Recursive Linear Regression |   70.11% |
| Holt                        |   68.46% |
| SES                         |   67.22% |
| ARIMA                       |   59.09% |
